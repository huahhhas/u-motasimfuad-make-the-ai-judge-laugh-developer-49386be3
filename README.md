Write one funny single-line excuse a developer gives when code breaks in production, under 200 characters. A judge model compares lines head to head in 3 private blind rounds, and the $3 reward is split over the top 10 places.

The entry:

> "It worked on my machine because my machine is the only environment that still believes in me."

## Run it

```sh
OUTPUT_DIR=/tmp/out python3 main.py
```

This writes the line above to `$OUTPUT_DIR/entry.txt` (default `/output`), with no trailing newline, and self-verifies the written file.
